Continuity scenarios

Illustrative runbooks only; tabletop validation remains required.

Primary hub unavailable for one business day

Trigger: Queue review confirms primary hub cannot perform scheduled work.

Fallback: Backup hub accepts priority cases from a shared queue; use the source map, current exception log and handover notes; defer non-critical change releases until the accountable reviewer is available.

Evidence: Handover checklist, accepted case ownership, open-risk list and next review time.

Validation: TABLETOP_REQUIRED; no exercise is claimed as completed.

Source feed fails validation during a migration window

Trigger: Required-field or reconciliation threshold breached in a synthetic release check.

Fallback: Hold affected records, preserve source extracts and reconciliation output, notify source and technology owners, and resume only after a documented retest and approval.

Evidence: Run identifier, source-to-target mapping version, exception log, retest result and checker sign-off.

Validation: ILLUSTRATIVE_RUNBOOK; no production feed or migration is connected.
